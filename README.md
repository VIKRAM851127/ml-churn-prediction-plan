# ML Model Development and Evaluation Plan: Customer Churn Prediction

Week 3 deliverable. A step-by-step plan for building, validating and maintaining a customer churn prediction model in Python. No code is executed; the document describes the full process.

## Contents
- `docs/Week3_ML_Model_Development_Plan.docx` - the full plan (14 pages)
- `figures/` - workflow, validation and maintenance diagrams used in the plan

## What the plan covers
1. Problem definition and justification
2. Data collection and understanding
3. Data preprocessing (cleaning, encoding, feature engineering, selection)
4. Model selection (logistic regression, trees, random forest, gradient boosting)
5. Training and hyperparameter tuning
6. Evaluation metrics (PR AUC, recall at top-k, F1, ROC AUC, calibration)
7. Validation strategy (time-aware cross-validation, final holdout)
8. Deployment and maintenance
9. Risks, effort plan and quality checklist

## Tools referenced
pandas, scikit-learn, LightGBM, Optuna, MLflow, SHAP, FastAPI, Docker
